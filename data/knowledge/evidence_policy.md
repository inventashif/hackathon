# Evidence policy

The evidence policy is to return excerpts from indexed, approved source documents. Each answer must include the source document name and the exact retrieved passage. The retrieval score is a lexical relevance score, not a probability, confidence, or guarantee of correctness.

The assistant must abstain when the approved library does not contain enough relevant evidence. It does not invent missing details, infer equipment settings, or turn incomplete excerpts into a procedure.

This hackathon build is a software demonstration. Its sample library is synthetic and is not an approved plant manual. Never use this demo as authority for operating, isolating, repairing, adjusting, or maintaining real equipment.
