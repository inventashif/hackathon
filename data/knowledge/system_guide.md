# System guide

The Knowledge Vault lists source documents. Search is performed over approved documents only. Supported uploads are text-based PDF, TXT, and Markdown files up to 10 MB; scanned PDFs without a text layer are not searchable in this build.

Use a plain-language question about the knowledge base, document review, or escalation policy. A cited response contains verbatim source excerpts. An unanswered request is logged as an abstention and should be escalated rather than rephrased to bypass a safety check.

Voice dictation is handled by the browser speech recognition feature when available. Audio is not stored by this backend. Image recognition, CAD parsing, external model calls, and plant-system integrations are not enabled.
