Presenter checklist
Follow the clicks, not a slide deck

Step-by-step demo

Before the judges arrive

  1. 1

    Start the backend. Double-click run.bat. Keep its terminal window open.

  2. 2

    Open the app. Visit http://127.0.0.1:8000/. Do not present the project-folder listing.

  3. 3

    Check readiness. Wait until the header reads API: ONLINE and the Knowledge Vault shows 3 demo documents.

Important: use only the included synthetic knowledge base in the presentation. Never upload confidential or real plant procedures to an unapproved service.

Optional: show review-gated upload

Adds about 30-45 seconds. Prepare a small synthetic TXT file before presenting.

Shift handover requests should be directed to the duty supervisor through the site's established escalation channel.
  1. Upload the file from Knowledge Vault. Show it is pending and excluded from search.
  2. Click "Approve for demo retrieval". Explain this local demo action is not authenticated.
  3. Ask: "Where should shift handover requests be directed?" Show the returned source.

Timed talk track

0:00-0:15

Say: "Industrial teams lose time searching manuals, and unsupported instructions can create safety risks. NexusSOP is designed to make evidence visible and missing evidence explicit."

0:15-0:40

Click: "Show cited evidence".
Say: "This is retrieved from an approved demo source. The passage is shown verbatim; the score is lexical relevance, not a confidence or correctness probability."

0:40-1:05

Click: "Test safety refusal".
Say: "For a PLC repair request, it does not invent steps. It refuses and directs the user to the current site SOP and a qualified supervisor."

1:05-1:20

Click: "Log escalation", then "Supervisor Dashboard".
Say: "The escalation and request outcomes are visible in the local supervisor view."

1:20-1:35

Close: give the honest limitation statement from page 1. Keep the upload flow as an optional extension if time allows.

If something goes wrong

  • Folder listing appears: open http://127.0.0.1:8000/, not the workspace folder.
  • API is offline: check the run.bat terminal for an error; restart it and reload the page.
  • No evidence found: use the built-in "Show cited evidence" prompt exactly.
  • Charts are blank: explain the metrics and continue; chart assets require internet access.
Do not claim: downtime reduction, production accuracy, certified safety, or real plant deployment. Those have not been measured or validated.
